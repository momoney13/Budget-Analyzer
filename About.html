About the Personal Budget Analyzer

The Personal Budget Analyzer is a web application designed to help people understand their day-to-day finances and make progress toward savings goals. Instead of showing a single calculation, it brings together income, expenses, and savings information so users can review their budget over time.

What the application does

Users enter income and expenses through forms and organize spending into categories. They can also create savings goals and record progress toward them. The application analyzes the saved information to show totals, compare income with expenses, summarize spending by category, and show how close a user is to each savings target. These results are intended to help users spot spending patterns and decide where they may want to adjust their budget.

How it is being developed

The application uses HTML to structure its pages and forms, CSS to provide a consistent and readable interface, PHP to process submitted information and perform the budget calculations, and a json flatfile to store the information between visits. The file is the application's external data source: PHP will read and update records there as users add or change their financial information. Keeping the data in a flatfile allows the application to build summaries from multiple entries rather than relying on a one-time form submission.

Development is organized around the main tasks a user needs to complete: reviewing a dashboard, managing income and expenses, and setting savings goals. The navigation connects these areas, while the shared colors, headings, and layout help the pages feel like one application. Form values will be checked before they are stored, and calculations will use the saved records so that the displayed summaries stay connected to the user's entries.
